AI-Based Trip Demand Forecasting

RideRush is a machine learning project that predicts taxi trip demand and estimates trip duration using historical trip data. It helps understand travel patterns and expected journey times.

Project Features

📈 Demand Forecasting

Forecasts taxi demand across different hours to identify busy and less busy periods.

⏱️ ETA Prediction

Estimates trip duration using trip distance, pickup time and other available trip features.

🤖 Machine Learning

Uses data preprocessing, feature engineering, model training and evaluation to make predictions.
