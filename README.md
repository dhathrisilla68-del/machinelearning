# 🚖 RideRush: AI-Based Trip Demand Forecasting and ETA Prediction System

## 📌 Project Overview
RideRush is a Machine Learning project designed to predict taxi trip demand and estimate trip duration using historical taxi trip data.

The project uses data preprocessing, feature engineering, machine learning models, model evaluation, and interactive visualizations to analyze taxi trip patterns.

## 🎯 Objectives
- Predict taxi demand for different hours.
- Estimate taxi trip duration.
- Analyze peak-hour and low-demand periods.
- Compare machine learning models.
- Visualize results through an interactive dashboard.

## 🛠️ Technologies Used

## 🚀 Run the Project Locally

### 1. Clone the repository
```bash
git clone https://github.com/dhathrisilla68-del/machinelearning.git
cd machinelearning
```

### 2. Create a virtual environment
```bash
python -m venv .venv
```

### 3. Activate the environment on Windows
```bash
.venv\Scripts\activate
```

### 4. Install dependencies
```bash
pip install -r requirements.txt
```

### 5. Run the dashboard
```bash
streamlit run dashboard.py
```
